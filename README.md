# Roster

Working name. A desktop and iOS client for [OpenClaw](https://github.com/openclaw/openclaw).

Roster connects to an OpenClaw gateway you already run and gives it a bots-first interface: your bots in a sidebar, tasks under each bot, the bot's work beside the conversation, and fine-grained control over each bot.

Status: early development. Nothing here is ready to use yet.
