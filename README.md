# Clawtrate

Your OpenClaw agents, orchestrated.

A desktop and iOS client for [OpenClaw](https://github.com/openclaw/openclaw).

Clawtrate connects to an OpenClaw gateway you already run and gives it a bots-first interface: your bots in a sidebar, tasks under each bot, the bot's work beside the conversation, and fine-grained control over each bot.

Clawtrate is an independent project and is not affiliated with OpenClaw or xAI.

Status: early development. Nothing here is ready to use yet.
