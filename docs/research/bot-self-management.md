# Bots that manage themselves: what OpenClaw 2026.10.6 allows a plugin

Research behind `docs/design/main-bot-onboarding.md` (issue #292). It answers what a Clawtrate plugin can do on OpenClaw 2026.10.6: register tools, limit them per bot, reach the gateway's own methods and with whose authority, run a model with no tools, keep records, and serve external agents over MCP.

`<openclaw>/…` is a path in the OpenClaw 2026.10.6 package this repository pins for the development gateway: CI installs `openclaw@2026.10.6` from npm (`.github/workflows/ci.yml` line 61), registry integrity `sha512-jSpQPa2Jw5rG0J2GC07j9+qHtVYIuoHjgccU88JeS+p7188sBCnvIJeuaiNPHj1zsWkuHcBv443QiEUh7qrxwA==`. The repository itself pins only `@openclaw/gateway-client` and `@openclaw/gateway-protocol`. The development gateway the probe ran was installed separately; its `dist/` and `docs/` were compared with that npm package file by file and are identical, so every line number here holds for the pinned package. Chunk names carry a build hash, so search by the `//#region` marker if a name changes. **Live** means the probe below ran it on a development gateway. **Source** means it was read only.

## Method

- A probe plugin, [`bot-self-management/probe-plugin/`](bot-self-management/probe-plugin/index.js), with one tool and four gateway methods, and a driver, [`bot-self-management/probe.ts`](bot-self-management/probe.ts).
- It ran twice on a fresh named development instance started with `pnpm dev-gateway start --instance <name> --with-plugin clawtrate-bots-probe` (the plugin folder copied into `plugins/` for the run), then the instance was reset and the copy removed.
- The driver paired three devices of its own: read, write (read and write) and admin (read, write and admin). It removed them before it exited.
- The scripted model played the tool call through three temporary scenarios that are not on `main`: `#probe-self` calls `clawtrate_probe_self {name: "Probe Renamed"}`, `#probe-other` calls it with `target: "otto"`, and `#probe-writes` with `writes: true`. Each is `[tool("clawtrate_probe_self", {...}), say("Probe done.")]` in `tools/dev-gateway/src/scenarios.ts`.

## What this means for the plugin

- **A turn's scopes don't authorize a write.** They are the connection's authority (4), they come with routines (18), and with no operator they reach admin anyway (6). An admin's chat can also carry untrusted text. So the plugin's tools only read and propose, and every write happens in a plugin method called by a person with admin after a decision bound to the exact values (7), rechecked at the effect.
- **The plugin draws every boundary itself**: the bot from the context (1), which bots it may propose for (5), and each proposal's binding.
- **The plugin approval card isn't that binding** (20): it is resolved at `operator.approvals` and isn't tied to an admin principal and the values.
- **Proposals are durable plugin records** with an atomic claim (22). A proposal's field is applied only with a precondition the gateway checks inside the write (23, 27, 28). `agents.update` and `cron.remove` have none (24, 27), and a read-back can miss a race, so applying a name, a picture or a routine removal from a proposal is gated until the gateway has such a write.
- **Describe is gated.** A completion with no tools exists (8, 25), but the plugin can't make it refuse a route other than the one shown (31).
- **External agents**: the gateway's attach grant is loopback-only, bound to one task, and acts as the bot with no operator (10, 6); plugin HTTP routes can't carry admin (11).

## Not established

- What a channel turn or a heartbeat carries as operator authority (a routine can carry its creator's, 18). The design doesn't depend on it: no turn's authority writes.
- Whether the tool context's `messageChannel` is trusted per-turn provenance in a shared main conversation.
- Whether a plugin's prompt guidance (`PluginAgentTurnPrepareResult`, `AgentPromptGuidance`, both exported from `openclaw/plugin-sdk/core`) reaches the model before a bot's first turn. The first run doesn't depend on it: the fixed opening asks the questions and Clawtrate's own card saves the answer.
- Renaming an implicit `main` through `config.patch` (16), on a gateway with no `agents.entries`.
