# Where each provider logo came from

The marks in `ProviderLogo.tsx`, one path each on a 24 × 24 grid, copied unchanged from two widely used open-source icon sets on 2026-11-27. A one-colour mark is drawn in the text colour (`currentColor`), so it reads on the dark and the light background; MiniMax is drawn in its brand colour from Simple Icons.

| Logo           | Set and file                                        | Where the set took it from                                                      | Licence                                                                             |
| -------------- | --------------------------------------------------- | ------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| OpenAI         | Lobe Icons 1.106.0, `icons/openai.svg`              | OpenAI's mark                                                                   | MIT (LobeHub)                                                                       |
| xAI            | Lobe Icons 1.106.0, `icons/xai.svg`                 | xAI's mark                                                                      | MIT (LobeHub)                                                                       |
| GitHub Copilot | Simple Icons 16.38.1, `icons/githubcopilot.svg`     | GitHub's Primer icons, `copilot-24` (primer.style/foundations/icons/copilot-24) | MIT, as Simple Icons records it                                                     |
| MiniMax        | Simple Icons 16.38.1, `icons/minimax.svg`, `E73562` | MiniMax's own repository, `MiniMax-AI/MiniMax-01`, `figures/minimax.svg`        | MiniMax's own terms, as Simple Icons records them (simple-icons pull request 13982) |
| OpenRouter     | Simple Icons 16.38.1, `icons/openrouter.svg`        | openrouter.ai                                                                   | CC0 1.0                                                                             |
| OpenCode       | Simple Icons 16.38.1, `icons/opencode.svg`          | OpenCode's own repository, `packages/identity/mark.svg`                         | CC0 1.0                                                                             |

Lobe Icons: the npm package `@lobehub/icons-static-svg` (github.com/lobehub/lobe-icons). Simple Icons: the npm package `simple-icons` (simpleicons.org), whose data file records each icon's source.

A provider without a logo here is still offered, under the gateway's own name, with the first letter of that name in place of a logo.
